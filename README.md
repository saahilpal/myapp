
 BudgetBytes - Mobile Device Comparison App

 🚀 Overview
BudgetBytes is an intuitive mobile device comparison application designed to help users compare the latest smartphones based on key specifications such as camera, performance, price, and display quality. With a modern UI and seamless user experience, BudgetBytes provides detailed insights into the devices' features and enables users to make informed decisions before purchasing their next phone. The application is powered by a SQL Server database for real-time device data and offers an interactive, engaging experience for the end-user.

 📱 Key Features
- Device Comparison: Compare smartphones from various brands (Samsung, Apple, Google, etc.) based on specs like camera, processor, price, and display.
- Performance Data: Display device performance details, such as processor name and ranking, without cluttering the UI.
- Wishlist Functionality: Add and manage devices to a personalized wishlist for future reference.
- Device Popularity: The app dynamically shows popular phones based on user interactions and wishlist data.
- Modern UI: A polished and visually appealing user interface designed with rounded corners, custom gradients, and smooth transitions for a seamless user experience.
- Database Integration: All data is backed by a robust SQL Server database, ensuring reliability and easy scalability.

 🖥️ Tech Stack
- Frontend: Visual Basic .NET (WinForms), Guna2 Controls, Custom UI Components
- Backend: SQL Server for data management (Devices, Wishlist, Performance, Feedback)
- UI Design: Guna2 controls, dynamic panels, rounded corners, color gradients, and consistent theme across all forms

 🎯 Goals
- Provide users with a comprehensive comparison of mobile devices using specifications and performance metrics.
- Highlight the better device automatically by comparing performance and other specs such as the camera, display, and price.
- Enhance the user experience with smooth animations, modern UI design, and consistent styling.

 ⚙️ Setup Instructions
 Prerequisites
- Visual Basic .NET: Ensure you have the .NET Framework set up to work with WinForms.
- SQL Server: You'll need a running instance of SQL Server to store device data.

 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/BudgetBytes.git
   ```

2. Set up the database:
   - Create a SQL Server database and import the provided schema to set up tables like `Devices`, `Wishlist`, `Performance`, and `Feedback`.
   - Ensure all necessary relationships between tables are maintained.

3. Run the project:
   - Open the project in Visual Studio or another compatible IDE.
   - Build and run the project to launch the BudgetBytes app.

 🧑‍💻 Usage
1. Launch the app and select devices from the dropdown lists.
2. Review the comparison of selected devices, highlighting the better device in terms of performance and specs.
3. Add devices to the wishlist and view the popular devices based on user interactions.
4. Provide feedback through the app for continual improvements.
